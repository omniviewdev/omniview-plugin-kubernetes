# Kubernetes 0.20.2

## Diagnostics

- Record safe action stages and Kubernetes error classifications for node drains, workload actions, CronJobs, Pod exec, and Helm actions.
- Propagate action trace context with plugin-sdk 0.19.2. The host must also use plugin-sdk 0.19.2 for correlated traces.

## Fixes

- Load initial informer inventories larger than the live-change queue without an overflow reset.

Requires Omniview 0.35.0 or newer. Correlated action traces require a host build that includes the SDK action tracing update.
