# Kubernetes 0.19.1

## Cluster explorer parity

- Restore the approved compact provider-first cards, single-line names, sourced metadata line, environment/status footer, rounded selection rail, and shared hover/selection motion.
- Keep full-width keyed search separate from filters and view controls. Show counted completions automatically; partial values such as `region:us-` keep matching clusters visible. First suggestions and results support immediate keyboard navigation without autocapitalization.
- Open clusters directly from their primary action. Keep Preview, Settings, pinning, and folder assignment independent.
- Restore environment grouping, a single-row Recent strip, branded navigation, and connected-first Debug cards. Table remains flat even after collapsing a card group and starts with curated identity columns on new profiles.
- Preserve manual drag/drop, automatic folder rules, custom images and reusable icon libraries, saved lenses, and backend-backed recent history. Place optional image naming inside the icon picker and keep rule dropdowns inside their accessible dialog layer.
- Keep collapse state local to each view and grouping. Organize honors the current folder, facets, and keyed query.
- Preserve account and project together, with an independent optional Project column. Count distinct prefix matches consistently between suggestions and results.
- Coalesce pending opens from Recent and main results within the explorer. Announce selected custom folder colors by their hex value.

## Compatibility and verification

Requires Omniview 0.32.1 or newer, runtime/Vite 0.32.1, Base UI 0.17.0, and Editors 6.2.2. Upgrade the desktop before installing this plugin. The SDK remains 0.18.0.

Verified with a real owned Kubernetes v1.36.2 API: 26 context aliases on one local control plane, zero Nodes, and no scheduler. Cards, Table, and Debug passed 1,080 theme/density/text-scale/viewport combinations; the optional Project column passed another 360. All 1,849 consumer tests passed, including five regressions reproduced before the review fixes. Native palette screenshots, keyboard completion, direct API navigation, folder rules/manual membership, custom-image persistence, and lens/recent persistence accompany the [parity evidence](../images/cluster-explorer-parity/index.json). Cloud connectivity and native OS file/color-dialog rendering were not claimed.
