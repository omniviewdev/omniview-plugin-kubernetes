# Kubernetes 0.15.1

## Reliable container logs

- **Stream without waiting for EOF.** Logs now borrow a generation-owned streaming client instead of the finite resource-response client. Both emitting and silent follow streams become ready promptly. Resource and watch response budgets stay unchanged. [#192](https://github.com/omniviewdev/omniview-plugin-kubernetes/pull/192)
- **Finish completed sources once.** Compatible SDK 0.14.6 stops reopening cleanly exhausted follow readers and replaying their history. Actual transport failures retain bounded reconnection. [SDK #60](https://github.com/omniviewdev/plugin-sdk/pull/60)

## All 46 column workspaces retained

Search Fields, Labels, and Annotations while the persistent Selected pane stays visible. Required columns remain locked; saved selections and Reset retain their existing behavior. Includes Pods and 45 more object views, including the dynamic custom-resource table.

**Requires Omniview 0.27.2 or newer.** Upgrade the desktop before installing this plugin. Uses matching runtime/Vite 0.27.2 and released SDK 0.14.6; preserves the deployed source-wire contract and stock grpc-go dependency.
