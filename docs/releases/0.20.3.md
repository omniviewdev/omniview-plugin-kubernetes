# Kubernetes 0.20.3

## Diagnostics

- Add tracing and classified diagnostics for authentication, connections, informers, resource operations, logs, exec, port forwarding, metrics, and Helm.
- Add plugin SDK 0.19.3 observability for connection lifecycles, sources, admission, and streams.
- Avoid logging EKS token responses and classify remote errors in diagnostics.

Requires Omniview 0.35.0 or newer.
