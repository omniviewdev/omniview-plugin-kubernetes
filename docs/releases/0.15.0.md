# Kubernetes 0.15.0

## Highlights

Find the columns you need without losing sight of your selection. Searchable column workspaces with a persistent **Selected** pane now cover Pods and 45 more Kubernetes object views, including the default custom-resource table.

- Search fields, labels and annotations by their full key.
- Select or clear matching results without changing unrelated columns.
- Keep required columns locked, preserve saved choices and restore defaults with Reset.

## Compatibility and release ordering

**Requires Omniview IDE 0.27.0 or newer.** Upgrade the host before installing Kubernetes 0.15.0. The plugin uses the published 0.27.0 runtime/Vite cohort and host-derived schema APIs; marketplace publishing enforces the same minimum host version.

For maintainers: publish and make the Omniview 0.27.0 desktop release available before publishing this plugin. Reuse the already-published runtime/providers/Vite 0.27.0 packages without republishing them. The Pod foundation and all 45 object-view changes are merged into main. Complete integration and release-packaging checks for this cohort before creating the Kubernetes 0.15.0 release tag. This preparation does not publish or tag a release.

The release workflow validates this versioned notes file alongside all four committed version fields. It transfers notes separately from plugin archives and uses this file as the GitHub release body, without appending duplicate generated notes.
