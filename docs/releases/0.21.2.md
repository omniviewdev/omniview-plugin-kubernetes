# Kubernetes 0.21.2

## Cluster loading

- Decode each resource record once. Dashboards, stat cards and pickers decoded every record of a collection on every live update; they now share the resource table's per-record cache, so only records that changed are decoded. Opening a cluster with about 1,000 pods spent 40.7% of wall time in script before this change and 2.8% after, measured in the desktop app together with the Omniview runtime change that reuses source views.
- De-duplicate dashboard events with numeric timestamp comparison and use a plain string as the list item key.

## Compatibility

Requires Omniview 0.36.0 or newer. Uses plugin SDK 0.20.0, Base UI 0.17.3 and Editors 6.2.5. The Go backend is unchanged from 0.21.1.
