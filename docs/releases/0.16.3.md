# Kubernetes 0.16.3

## Changes

- Resource tables display safe details from structured errors instead of `[object Object]`. This improves diagnostics; it does not fix the underlying ReplicaSet load failure. [Fix resource table error details](https://github.com/omniviewdev/omniview-plugin-kubernetes/pull/214).
- Migrate supported saved Kubernetes resource paths, table preferences, and sidebar order to canonical resource identifiers. Original values are retained, and unknown or ambiguous entries are reported. [Migrate saved Kubernetes choices](https://github.com/omniviewdev/omniview-plugin-kubernetes/pull/76).

## Compatibility and verification

Requires Omniview 0.30.2 or newer. The companion host saved-reference migration merged after the 0.30.2 release. Native migration checks used a development candidate; merged-source and packaged-desktop verification remain outstanding.
