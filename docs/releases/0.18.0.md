# Kubernetes 0.18.0

## Changes

- Report bounded plugin diagnostics to Omniview through plugin-sdk 0.17.0: Kubernetes API calls by operation and outcome, API latency, open watch streams, connection-check results and port-forward sessions. Attribute values come from fixed sets; no cluster, namespace, resource or path names are recorded. [Report bounded plugin diagnostics](https://github.com/omniviewdev/omniview-plugin-kubernetes/pull/218).

## Compatibility and verification

Works with any Omniview host. Hosts that include plugin diagnostics polling (merged to Omniview main after the 0.30.x releases) show these measurements in Performance views, captures and comparisons; older hosts ignore them. Verified on a development build against a local kind cluster; packaged-desktop verification is outstanding.
