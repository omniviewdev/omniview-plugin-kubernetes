# Kubernetes 0.18.1

## Go and Kubernetes dependency upgrade

- Build with Go 1.27 and move to client-go, api and apimachinery 0.37.2, controller-runtime 0.25.2, Helm 3.22.1, gRPC 1.85 (scoped grpc-go fork rebased onto v1.85.0), Polaris and aws-sdk-go-v2, plus the remaining Go dependencies.
- Follow the client-go 0.37 move of `httpstream` to `k8s.io/streaming`: exec and attach still fall back from WebSocket to SPDY when the API server refuses the upgrade.
- Adapt to the Polaris audit API, which now takes a context.
- Drop `GOEXPERIMENT=jsonv2`; `encoding/json` is backed by the v2 implementation in Go 1.27.
- Keep the bounded plugin diagnostics added in 0.18.0.

[Upgrade Go dependencies](https://github.com/omniviewdev/omniview-plugin-kubernetes/pull/217). Coordinated with [plugin-sdk #69](https://github.com/omniviewdev/plugin-sdk/pull/69) and [Omniview #435](https://github.com/omniviewdev/omniview/pull/435).

## Compatibility

This release is built with plugin-sdk 0.18.0. Compatibility with Omniview hosts is unchanged from 0.18.0; the upgraded host is coordinated in Omniview #435.
