# Kubernetes 0.21.0

## Browse-first cluster loading

- Connect with bounded discovery, scope, and native identity acquisition. Do not fetch OpenAPI or start every resource informer during connection startup.
- Keep resource representations independent of schemas. Explicit catalog refresh updates discovered support; ordinary catalog observation performs no native network work.
- Fetch native OpenAPI only for the selected editor's group/version. Coalesce concurrent demand, bound staging and retained bytes, and retire demand with its owning connection generation. Missing or denied schemas do not block raw resource browsing.
- Preserve published schema references under retention pressure. Refuse additional schema retention with `RESOURCE_LIMIT` until discovery withdrawal or connection retirement frees capacity; raw browsing remains independent.
- Preserve complete initial informer inventory and ordered live updates without consuming the live-change queue for the initial snapshot.

## Editors and forms

- Resolve Helm values schemas from one exact installed release and observed storage generation, not a route-wide Secret inventory. Recheck concurrent upgrades and reinstallations; support named reads for non-Kubernetes Helm storage. Do not apply an installed chart's schema to a replacement chart.
- Give each mounted editor its own schema registration and model URI. Keep drafts, Secret content, and optional form enrichment separate from shared browse data.
- Keep required submission admission active in YAML mode without mounting form controls. Manual Endpoints still verifies selectorless Service ownership and rejects stale or denied prerequisites.
- Resolve owner links from discovered native catalog types without extra aggregated-discovery negotiation or OpenAPI acquisition, including servers that support only v2beta1 or unaggregated discovery.
- Use the shared table's overscan policy instead of overriding it in the plugin.

## Compatibility

Requires Omniview 0.36.0 or newer. This release uses resource wire 3 and host callback broker 2; earlier desktops cannot activate this cohort. Upgrade the desktop before activating the plugin.

Uses plugin SDK 0.20.0 and runtime/Vite packages from the 0.36 line. Base UI 0.17.2, Editors 6.2.4, and the scoped grpc-go fork remain unchanged. Existing node drain/action diagnostics and authentication, informer, resource, log, exec, metrics, and Helm telemetry remain supported.

These changes do not claim measured release-cohort performance gains or resolution of every renderer stall. Coordinated source, published-dependency, archive, and native acceptance remain release gates.
